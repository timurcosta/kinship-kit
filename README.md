# Семейные исследования с Claude Code

Набор, с которым Claude ищет предков по базам и архивам бывшего СССР, собирает отчёт с доказательствами и делает из него сайт для родных.

- `CLAUDE.md` — правила для Claude. Главное из них: **не отмазываться письмами**. Пока не пройдены все онлайн-базы, ответ «дальше только написать в архив» запрещён. Черновики писем Claude кладёт в `requests/` и тем же ходом ищет дальше. Ещё там рабочие приёмы для ОБД «Мемориал», «Памяти народа» (в том числе через API сайта), Яндекс-архивов, FamilySearch и других источников.
- `skills/kinship-site` — навык, который делает из готового отчёта сайт: карта с путём по датам, документы, хронология, история версий. Выкладывается по секретной ссылке.
- Навык самого исследования, `ex-ussr-kinship-research`, ставится из репозитория автора: [DenisSergeevitch/ex-ussr-kinship-research](https://github.com/DenisSergeevitch/ex-ussr-kinship-research).

## Установка

```bash
git clone https://github.com/timurcosta/kinship-kit ~/kinship-kit
zsh ~/kinship-kit/install.sh ~/genealogy
```

`~/genealogy` — папка, где будут лежать дела, её можно назвать как угодно. Скрипт ставит оба навыка в `~/.claude/skills` и кладёт `CLAUDE.md` в эту папку. Если там уже есть свой `CLAUDE.md`, новый ляжет рядом под именем `CLAUDE.from-timur.md`.

Ещё понадобится:
- расширение [Claude in Chrome](https://claude.ai/chrome): «Память народа» и FamilySearch показывают капчу автоматическому браузеру, а через расширение Claude работает в твоём обычном Chrome;
- модель Opus (`/model`).

## Как начать

Открой Claude Code в `~/genealogy` и напиши:

> Используй навык ex-ussr-kinship-research. Заведи дело `<фамилия>/`. Что известно: <кто, годы, места, что рассказывали в семье, какие есть документы и фото — положи их в `<фамилия>/inputs/`>. Цель: <например, найти, где воевал и где похоронен прадед>.
> Ищи только онлайн и раздавай независимые маршруты субагентам параллельно. Письма в архивы — только черновики в `requests/`, это не повод останавливаться. Не говори «дальше только офлайн», пока не пройден онлайн-чеклист из CLAUDE.md и каждый пункт не записан в журнал поиска.

Продолжать потом так:

> Продолжи дело `<фамилия>` с research-state.md. Что дальше — только онлайн.

Если Claude всё-таки свернул на письма:

> Это офлайн. Покажи журнал поиска: какие пункты онлайн-чеклиста пройдены и какими запросами. Пройди остальные.

## Чтобы не пинать каждые 10 минут

- **Нужен Claude Code, а не чат.** Чат не держит долгую работу: он не запускает скрипты в фоне и не хранит дело в папках между сессиями. Claude Code есть в приложении Claude для компьютера (вкладка Code) и в терминале.
- **Режим без вопросов.** Чаще всего Claude стоит потому, что ждёт «можно?» на каждую команду. Shift+Tab переключает режимы: выбери auto или «принимать правки».
- **Работа по кругу.** Команда `/loop` (без интервала) сама запускает следующий шаг, пока работа не кончится:

  > /loop Продолжи дело `<фамилия>` с research-state.md: возьми следующий непройденный пункт онлайн-чеклиста из CLAUDE.md, раздай маршруты субагентам, запиши результат в реестры и журнал поиска. Когда онлайн-маршрутов не останется, остановись и покажи журнал.

- **Субагенты.** Пусть раздаёт независимые маршруты параллельно (ОБД, «Память народа», книги памяти, Яндекс-архивы): так за то же время проходится в несколько раз больше.

Когда отчёт готов:

> Сделай семейный сайт навыком kinship-site. Сначала покажи локально, выкладывать после моего «пушим».

## Что Claude не делает

- Не обходит капчи: вход и капчу делаешь ты, он в это время ищет по другим базам.
- Не отправляет письма без твоего «отправляй».
- Не выкладывает семейные документы без согласия. Сайт открывается по секретной ссылке, поисковики его не индексируют.
- О живых пишет минимум: имя и роль в семье.

Найденные приёмы и твои пожелания Claude сам дописывает в `CLAUDE.md` и в навык сайта, так что набор пополняется по ходу работы.
