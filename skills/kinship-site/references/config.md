# Поля site.json и story.json

Оба файла лежат в `pdf-source/web/` дела. Тексты можно писать с HTML-тегами (`<b>`, `&nbsp;`).

## site.json — страница

| поле | что это |
|---|---|
| `title`, `brand`, `brandLong` | заголовок вкладки и логотип: «Ивановы» + «: семейная история» |
| `kicker`, `h1` | строка над заголовком и сам заголовок; подзаголовок берётся из `<p class="sub">` отчёта |
| `ctaMap` | текст главной кнопки, например «Открыть карту и путь дивизии» |
| `pdf`, `publicPdf` | имя PDF в деле (может быть кириллицей) и латинское имя на сайте |
| `naturalEarth` | папка слоёв Natural Earth, по умолчанию `~/.cache/kinship-site/naturalearth` |
| `hosting.bucket`, `hosting.repo` | бакет Object Storage (секретная ссылка: имя со случайным хвостом) и приватный репозиторий GitHub |
| `heroPhoto` | `src` (путь от `pdf-source/`), `alt`, `caption`; если файла нет, фото не показывается |
| `tree.gens[]` | поколения сверху вниз: `label` и `people[]` |
| `tree.gens[].people[]` | `id`, `name`, `sub`, `parents` (id родителей, от них идут линии), `place` (ключ места на карте), `tag` + `tagText`, `dashed` (родство не доказано) |
| `mapHint`, `footer` | подсказка под картой и подвал |
| `mapFigures` | `{"map-family.svg": "family"}`: у рисунка карты в отчёте появится ссылка на этот вид интерактивной карты |
| `placeOverrides` | координаты вручную: `{"key": {"lat": .., "lon": ..}}` или от другого места: `{"key": {"from": "peredovaya", "dlat": 0.095, "dlon": -0.135, "note": "почему"}}` |
| `timeline` | `section`: заголовок раздела с таблицей хронологии; `defaultYear`; `special`: `{"перед войной": 1940.5}` — фраза → год для сортировки |
| `basemap.bbox` | `[lon0, lat0, lon1, lat1]`: район, который вырезается из Natural Earth; брать с запасом вокруг всех видов |
| `basemap.lakes` | какие озёра рисовать (по имени в Natural Earth). Водохранилищ, которых тогда не было, не добавлять |
| `basemap.riversNamed` | реки, которые рисуются всегда (английские имена Natural Earth); остальные появляются при приближении |
| `basemap.riverLabels` | `[["Дон", lat, lon], …]` |

## story.json — карта

- **`views`**: `{"key": {"title": "Июль 1942: окружение", "bounds": [[lat0, lon0], [lat1, lon1]]}}`. Первый вид открывается по умолчанию, порядок задаёт порядок вкладок.
- **`kinds`**: типы значков, `{"home": {"label": "дом семьи", "color": "#7a2e1f"}}`.
  - Рисунки есть для `home`, `birth`, `missing`, `death`, `pow` (наручники), `division` (флаг), `event` (звезда), `station` (вагон), `ref` (точка «город для ориентира»).
  - Тип `enemy` — это кнопка, которая показывает и прячет слой фронта.
  - Те же цвета и подписи использует `maplib` для легенды PDF-карт.
- **`places[]`**:
  - `key` — по нему ищутся координаты в `geocode.json`; `name`; `q` — текст запроса для `geocode.py`;
  - `kind`, `views` (на каких видах показывать), `approx` (пунктирная обводка — место приблизительно);
  - `dir` — куда ставить подпись: `right`, `left`, `top`, `bottom`; `short` — подпись для телефона;
  - `events[]`: `date`, `text`, `tag`, `img` (путь от `pdf-source/`, кнопка «Открыть документ»).
- **`routes[]`**: `{"view": "july", "stops": ["belovodsk", "mityakinskaya", "grekovo"]}`. Пунктирные стрелки с номерами между местами.
- **`player`**: `{"title": "Путь 296-й дивизии…", "year": 1942, "label": "путь дивизии", "group": "Путь дивизии"}`.
  - `year` дописывается к датам шагов;
  - `label` — название фильтра в хронологии;
  - `group` — группа, куда попадают картинки шагов в галерее.
- **`steps[]`**: шаги плеера.
  - `date` («12 июля»), `view`, `focus` (ключи мест, на которые наводится карта), `title`, `text`;
  - `quote` и `src` (цитата из документа и откуда она), `tag`, `img`;
  - `y` — год для хронологии, если в `player.year` его нет.
  - Без шагов плеер не показывается.
- **`front[]`** — слой фронта. Координаты везде `[lat, lon]`:
  - `{"type": "thrust", "view", "label", "short", "path": [[lat, lon], …], "at": 0.3, "dir": "top", "text", "src", "tag"}` — синяя стрелка удара:
    - стрелка сужается к хвосту, наконечник идёт по той же кривой;
    - `at` — где на ней стоит значок танка (доля длины), `dir` — куда подпись;
    - сильный изгиб в самом конце делает наконечник кривым, поэтому последний отрезок лучше держать почти прямым.
    - `scale` — толщина стрелки (1 по умолчанию, рассчитано на вид шириной ~300 км; для вида ~100 км — около 0.35).
  - `{"type": "pocket", "label", "date", "center": [lat, lon], "centerNarrow": [..], "ring": [[lat, lon], …]}` — котёл, красный пунктир:
    - `ring` сглаживается;
    - `centerNarrow` — где поставить подпись на телефоне, если в центре тесно.
  - `{"type": "escape", "label", "short", "path", "at"}` — пунктирная стрелка «куда прорывались наши». Прячется вместе с типом `division`. `dir` — сторона подписи (`right` по умолчанию).
  - Нажатие на любой элемент показывает `text`, «Источник: `src`» и пометку `tag`.

## Несколько линий и языков

- **`site.json` → `langs`**: `["ka", "ru"]`. Первый язык — `index.html`, остальные — `<lang>.html` и `data/story.<lang>.js`. Любое текстовое поле `site.json` и `story.json` может быть `{"ka": "…", "ru": "…"}`. `langNames` — подпись кнопки языка (`{"ka": "ქარ", "ru": "Рус"}`), `fonts` — CSS-ссылка Google Fonts (для грузинского — Noto Sans/Serif Georgian), `ui` — замены подписей из `assets/ui.json`.
- **`site.json` → `lines[]`**: `key`, `label` («Линия отца»), `surname`, `place` (строка под именем в карточке), `color`, `facts` (номера пунктов лида для карточки, например `[0, 3, 4]`), `report` (путь от папки дела, по языкам), `pdf` и `publicPdf` (по языкам). Без `lines` сайт — обычный, с одним отчётом.
- В дереве у человека `line` (полоса и линии родства цвета линии); `{"spacer": true}` — пустое место, чтобы ветка линии стояла под своими предками (на телефоне скрывается).
- В `story.json` поле `line` есть у видов, мест, маршрутов, шагов и строк хронологии. Вид без `line` общий и показывает места всех линий. У значка места с `line` — кольцо цвета линии; маршрут рисуется цветом линии.
- `player.byLine`: `{"zh": {"title", "label", "group"}}` — заголовок плеера, название фильтра хронологии и группа документов для каждой линии.
- `story.json` → `chrono[]`: `{d, text, tag, y, line}` — строки хронологии, если в отчёте нет таблицы «Хронология».
- `basemap.coastTolerance` (0.01) и `riverTolerance` (0.006) — огрубление берегов и рек в градусах. Для большой области (Кавказ — Венгрия) 0.04 и 0.02 держат `geo.js` меньше 1 МБ.
- Хостинг: `init_site.py` без поля `pdf` убирает PDF из `.gitignore` и `deploy.yml` (PDF лежат в `web/pdf/`).

## version-notes.json

`{"<первые 7 знаков коммита>": "Название версии для семьи"}` заменяет неудачное сообщение коммита в «Истории версий». На сайте с несколькими языками название можно дать по языкам: `{"<sha7>": {"title": {"ru": "…", "ka": "…"}}}`.

Версия — это коммит с новыми сведениями: изменился текст отчёта, шапка, дерево или тексты карты (места, события, шаги, подписи фронта). Коммиты, где поменялся только вид (стрелки, значки, вёрстка, движок), отдельной версией не показываются. Они входят в предыдущую версию: её снимок показывает последнее состояние, а дата и название остаются от коммита с новыми сведениями. Принудительно можно так: `{"<sha7>": {"title": "…", "show": true}}` показать версию отдельно, `"show": false` присоединить к предыдущей.
